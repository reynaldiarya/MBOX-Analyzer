## Description

MBOX Analyzer is a robust, interactive web application designed to transform raw email archives into actionable intelligence. By processing standard `.mbox` and `.mbx` files—such as those generated by Google Takeout—the platform enables users to gain deep insights into their digital communication patterns. It addresses the complexity of managing massive email datasets by providing specialized analytics for sender behavior, domain distribution, and communication timelines, making it an essential tool for digital forensics, personal data auditing, and inbox optimization.

## Features

- **Advanced Sender Analytics** - Identify and rank top contributors to your inbox with granular frequency metrics
- **Domain Intelligence** - Map communication patterns across organizations and service providers
- **Dynamic Timeline Visualization** - Analyze email volume trends over weeks, months, or years to spot communication spikes
- **Automated Spam & Newsletter Detection** - Intelligent identification of marketing and high-frequency automated senders
- **Granular Data Filtering** - Real-time filtering by date ranges, specific senders, or domains for focused investigations
- **Export Capabilities** - Generate comprehensive CSV reports containing the full processed dataset for external analysis
- **Zero-Persistence Processing** - Secure handling of sensitive email data using temporary storage and automatic cleanup

## Installation Guide

### Prerequisites

- Python 3.9 or higher
- pip (Python package manager)
- Virtual environment (recommended)

### Steps

1. Clone the repository to your local system

```bash
git clone https://github.com/reynaldiarya/MBOX-Analyzer.git
cd MBOX-Analyzer
```

2. Initialize and activate a virtual environment

```bash
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On Linux/macOS:
source .venv/bin/activate
```

3. Install required dependencies

```bash
pip install -r requirements.txt
```

4. Launch the application

```bash
streamlit run app.py
```

## Configuration

The application utilizes environment variables for runtime constraints. Create a `.env` file in the root directory based on `.env.example`.

### Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `DEFAULT_TOP_N` | Default number of results to display in tables | `20` |
| `MAX_TOP_N` | Maximum allowable limit for result rankings | `100` |
| `MIN_TOP_N` | Minimum allowable limit for result rankings | `5` |

## Usage

### Analytical Workflow

1. **Upload**: Use the sidebar to upload your `.mbox` or `.mbx` file.
2. **Analysis**: The engine automatically processes the archive upon successful upload.
3. **Navigation**: Use the sidebar radio buttons to switch between analytical views:
   - **Overview**: High-level metrics including total emails and unique senders.
   - **Top Senders/Domains**: Distribution charts and ranked data tables.
   - **Timeline**: Interactive line charts showing activity over time.
   - **Spam/Newsletters**: Targeted views for automated mail detection.
4. **Export**: Download the full processed dataset via the sidebar export button.
